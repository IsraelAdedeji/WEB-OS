# SPACE OS
This is a web based OS designed with a space theme, and is supposed to function as a cool way to learn about space and stellar bodies
I made it following a tutorial initially, but chose to divert later on with my own features to truly make it my own.

it features;
- Window Management system: windows can be opened closed, dragged and clicked to bring them forward above other windows
- live taskbar: A taskbar that tracks real time, and is designed to stay in the foreground above all windows at all times
- App1: Golden record functions as a sort of notes app where you can write down your thoughts
- App2: Planet Index serves as an information source for the 9 planets in the solar system
- App3: Quantum Calc works as an in built calculator app for the OS
- App4: Warp Web serves as a pre processor for accessing the web, it opens a new tab with the search results.

## How to Run
Try it out here : https://israeladedeji.github.io/WEB-OS/
or
- clone this repo, and open the index.html file in your browser
